# Power BI Data Analysis

## Project Overview

This project focuses on analyzing data and presenting meaningful insights using Microsoft Power BI. An interactive dashboard was created to visualize key metrics, trends and patterns in the dataset.

## Tools & Skills

- Microsoft Power BI
- Data Cleaning
- Data Transformation
- Data Visualization
- DAX
- Dashboard Design
- Data Analysis

## Project Work

- Imported and prepared the dataset for analysis.
- Cleaned and transformed data using Power Query.
- Created calculated measures using DAX.
- Designed interactive visualizations and dashboards.
- Analyzed trends and key performance indicators.
- Presented insights through an interactive Power BI dashboard.

## Key Learning

This project helped develop practical skills in data preparation, DAX, visualization, dashboard design and business-oriented data analysis.
